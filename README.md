# Java CLI Task Tracker

A simple Object-Oriented Programming (OOP) command-line application built with Java on macOS.

## Features

- Add new tasks dynamically

- View task list with status indicators (`[ ]` / `[X]`)

- Mark tasks as completed

- Interactive CLI menu

## Technologies Used

- Java 17+

- OOP Concepts (Classes, Objects, Encapsulation)

- `ArrayList` & `Scanner`

## How to Run

```bash

cd src

javac Main.java Task.java

java Main
